# 平台适配手册：小红书 vs 公众号

拆解与复刻时，必须先确定目标平台，套用对应规范。两者内容形态、分发逻辑、文案节奏差异很大。

## 差异总表

| 维度 | 小红书 | 公众号 |
|---|---|---|
| 内容形态 | 图文笔记：封面 + 标题 + 正文 + 多图 | 图文文章：标题 + 正文 + 排版 + 首图 |
| 标题 | 口语化、短、带 emoji / 数字 / 悬念，前 20 字决定点击 | 标题党 + 数字 / 悬念，但更「可点开」，忌过度诱导 |
| 正文 | 短平快、多分行、每行一两句、大量空行、重 emoji | 可长文、有段落、小标题、可深度 |
| 标签 | `#话题标签` 重要，决定搜索流量 | 基本不用 `#`，靠标题 + 关键词 |
| 封面 | 极其重要，决定点击率 | 无封面，靠标题 + 首图 |
| CTA | 点赞 / 收藏 / 关注 / 私信 / 评论区引导 | 关注 / 在看 / 转发 / 加微信 / 菜单 |
| 分发 | 搜索 + 推荐（长尾） | 订阅 + 朋友圈 / 群传播 |
| 违禁 / 敏感 | 绝对化用语、医疗金融、引流词审查严 | 标题党、诱导分享、引流词审查 |

## 小红书 checklist

- [ ] 标题 ≤ 20 字左右，含数字 / emoji / 悬念之一
- [ ] 正文分行短句，一段 1–2 句，多用空行
- [ ] 带 **8–16 个 `#标签`**（实测 10 条爆款中位约 10 个），泛流量词 + 精准词 + 长尾词组合
- [ ] 给出封面文案 + 封面图建议（大字标题式封面最稳）
- [ ] **正文常在图片里**：很多图文笔记的文案只有标题 + 一句短描述，主体内容做成图片，规划时别只写文案
- [ ] CTA 可选：多数图文爆款**不放显式 CTA**，靠内容 + 标签承接流量；要放就放软引导，避免引流词
- [ ] 口语化、有第一人称体验感

## 公众号 checklist

- [ ] 标题 15–25 字，含数字 / 悬念 / 痛点之一，忌绝对化
- [ ] 正文有结构：开头钩子 → 小标题分节 → 结尾引导
- [ ] 排版：段落适中、小标题、可加引用 / 列表
- [ ] 首图建议（可无封面，但首图影响打开率）
- [ ] CTA 引导「关注 / 在看 / 转发」，引流加微信需谨慎
- [ ] 长文可适度深度，但开头 3 行决定是否继续读

## 复刻时的注意

- 同一套「情绪曲线 / 信息结构」可跨平台复用，但「标题写法、正文节奏、标签、封面」必须按平台重写。
- 小红书偏「短 + 情绪 + 种草」；公众号偏「标题 + 结构 + 留存」。
