# 截图 OCR（视觉转写）方法论

本 skill 运行在 Codex / Claude 等多模态代理里，截图直接用代理的视觉能力转写为文本，**无需额外 OCR 引擎或 API**，保持零依赖、agent-native。

## 何时用

- 用户丢来小红书 / 公众号截图（单张或多张），要拆解或复刻。
- 截图可能包含：封面图文字、标题、正文、标签、评论区、作者信息。

## 转写步骤

1. **读图**：用视觉识别截图里的全部文字，按区域整理。
2. **分离结构**：
   - 封面文字（大字标题 / 卖点）
   - 标题
   - 正文（按段落）
   - 标签（`#` 开头）
   - 评论区 / 互动（若有）
   - 作者名 / 头像 / 粉丝数（涉及隐私，默认忽略，不写进产出）
3. **多图拼接**：小红书正文常多页，按顺序拼接，标注「图 1 / 图 2 …」。
4. **长图滚动截图**：公众号长文可能被截成多段，按视觉顺序拼接，注意段落衔接。

转写结果就是「文本」，之后走标准五步 Pipeline（先 `scripts/breakdown.js` 再定性分析）。

## 不确定性处理（重要）

- 看不清的字用 `[?]` 占位，**不要脑补**。
- 模糊的数字 / 价格 / 数据：标「数字不清，需用户确认」，不臆造。
- 整张图太糊无法转写时，让用户提供更清晰截图或直接粘贴文本。

## 隐私与合规

- 作者昵称、头像、评论区用户信息不写入产出，避免仿冒与隐私泄露。
- 只转写「结构」，后续仍走原创护栏，禁止照搬原文。

## 兜底

- 若运行环境不支持读图（纯文本代理），明确告诉用户：请直接粘贴文本。
- 可选：未来可加 tesseract.js 做脱离代理的独立 OCR（见 Roadmap）。
