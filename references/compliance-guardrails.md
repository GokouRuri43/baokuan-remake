# 合规护栏

复刻必须「原创 + 合规」。以下清单是硬约束，产出前逐项自检。

## 一、原创护栏（不可违背）

- **只拆结构，不搬句子**：禁止逐句搬运原文，禁止「换几个词」的洗稿。
- **换表达要彻底**：同义改写需换句式 + 换例证 + 换顺序，达到「看不出原文痕迹」。
- **不仿冒身份**：禁止伪造「我是原博主」「原博主的亲述」。
- **数据可溯源**：引用具体数字 / 案例须标注来源或明确标「示例」。
- **用户要求照抄 / 洗稿时，拒绝并解释边界。**

## 二、违禁 / 敏感词类目（非穷尽，需结合平台最新规则）

- 词库见 `data/forbidden-words.json`（可按平台扩充），共 6 类：绝对化/夸大、医疗健康、金融投资、引流导流、教育升学、其他违禁。
- 用脚本自动扫描产出稿：

```bash
node scripts/compliance-check.js <成品文件或 --text "...">
```

- 命中时**列出并给出替换建议**，而非直接删掉让用户无感。
- 词库非穷尽，医疗 / 金融 / 引流是平台重点审查区，宁严勿松。

## 三、广告合规（带货 / 种草必看）

- **标注广告**：品牌合作、赞助、带货内容须按平台要求标注「广告 / 赞助 / 合作」，隐藏广告可能违反《广告法》。
- **不虚构使用体验**：不得编造未发生的使用感受、效果或前后对比。
- **功效宣称有据**：不得宣称产品不具备的功效；食品 / 化妆品不得宣称医疗作用。
- **对比要真实**：不得贬低同类产品，对比数据须可验证。
- **区分推荐与商业合作**：真实自用推荐与商业推广要讲清楚，别让用户误判。

## 四、去 AI 味清单

- 删除：首先 / 其次 / 最后 / 综上所述 / 总而言之 / 值得注意的是。
- 减少：排比套话、模板化过渡句、每段结构完全一致。
- 增加：具体细节、真实数字、第一人称体验、口语化短句。
- 长短句交替，避免「一逗到底」。

## 五、免责声明

- 拆解是方法论，**不保证爆款、不保证涨粉**。
- 产出需**人工复核**后发布，不替代平台合规审查。
- 示例数字默认虚构，仅作格式演示。

## 六、发布前自检清单

- [ ] 正文是否完全原创，无原文逐句痕迹
- [ ] 是否命中绝对化 / 医疗 / 金融 / 引流等敏感词
- [ ] 数字 / 案例是否标注来源或「示例」
- [ ] 若为品牌合作 / 带货，是否已标明广告、且使用体验真实
- [ ] 是否已做去 AI 味处理
- [ ] 是否附上「不保证结果」的说明（面向用户的成品可省略，但 skill 内部始终遵守）
