# 热梗 / 趋势识别

爆款分两类：**结构驱动**（干货、清单、教程——靠公式赢）和**梗 / 趋势驱动**（靠当下热梗、热点、人设体赢）。只拆结构，会漏掉第二类，也就说不清「为什么是**现在**爆」。

## 一、热梗的常见形态

| 形态 | 例子 | 识别信号 |
|---|---|---|
| 句式梗 | 「你胆子真是肥嘟嘟的」 | 可套用句式 + 叠词 |
| 叠词 / 反差搭配 | 「肥嘟嘟」「软怼」 | 反常搭配：凶狠词 + 萌系叠词 |
| 文学体 / 人设体 | 古风帝王体（朕 / 陛下 / 爱卿）、发疯文学、xx 文学 | 强人设口吻，与选题本身无关 |
| 谐音 / 缩写 | yyds、栓 Q | 拼音缩写、谐音 |
| 表情包 / BGM 配套 | 特定梗图、卡点音乐 | 图文里出现梗图 |
| **概念造词型热词** | 「衣服死了」（洗不干净、一发汗就臭的衣服） | 给常见痛点起了个新名字，被当话题传播 |
| **品牌借势型** | 品牌把热词做成文案 / 梗图 | 商业节点，注意广告标识 |

## 二、识别流程（必须联网验证，不可凭感觉）

1. **扫描可疑词**：叠词、反常搭配、引号包裹的无实义词、看不懂的黑话。
2. **联网搜索验证**（关键，不可省）：
   - 搜「<词> 什么梗」「<词> 出处」「<词> 什么意思」
   - 看是否有百科词条 / 新闻 / 大量 UGC 在讨论
3. **判断热度与时效**：看搜索结果日期，越近越新；注意梗的「保鲜期」。
4. **判断类型**：梗驱动 / 结构驱动 / 两者兼有。
5. **判断二次传播机制**：是否易被模仿、接梗（同款句式、评论区接龙、模板可复制）。
6. **搜不到时**：明确写「未能验证为热梗」，**不要编出处**。

## 三、拆解报告里的「热梗 / 趋势因子」栏

```
热梗 / 趋势因子：
- 是否梗驱动：是 / 否 / 部分
- 命中的梗：<梗名 + 出处 + 含义>
- 时效：<当下正热 / 已过气 / 常青>
- 二次传播机制：<为什么容易被模仿转发>
- 可复用方式：<怎么嫁接到用户选题>
```

## 四、把梗嫁接到用户选题（核心手艺）

公式：**热梗句式骨架 + 用户的垂直场景**

1. 拆出梗的**句式骨架**（如「你 X 真是 Y 的」）。
2. 找用户选题里能填进 X、Y 的**反差元素**（狠话 + 萌、专业 + 沙雕、严肃 + 搞笑）。
3. 保持梗的**语气**，替换**内容**，产出原创。
4. **不要硬蹭**：梗和选题八竿子打不着就别用，硬蹭比不用更尴尬。

## 五、风险

- **过期翻车**：梗有保鲜期，用过气梗显得尬；发布前再确认一次。
- **平台差异**：同一梗在小红书和公众号的接受度不同。
- **版权 / 肖像**：梗图有版权，商用慎用。
- **合规**：梗里可能夹带低俗 / 敏感词，走违禁词自检。

## 六、进阶：「概念造词」——把痛点变成热词

「衣服死了」不是玩梗，而是**给一个常见痛点起了个新名字**。这类词比梗更持久、更好复用——而且用户可以自己造：

1. 找到一个大家都经历过、但**没被命名**的痛点（如「衣服明明洗了，一发汗就臭」）。
2. 起一个**形象、可复述**的名字（「衣服死了」「XX 税」「XX 黑洞」）。
3. 用「说的是那种……」「这不就是说我吗？」的句式**定义 + 自嘲代入**。
4. 让它变成标签，方便别人对号入座、二次讨论。

拆解时遇到这类词，同样要联网验证是否已成热词；**复刻时可以主动替用户的痛点造一个新词**——这是比蹭梗更可控、更不容易过期的打法。
