# 垂直赛道模板库

不同赛道的痛点、标题公式偏好、内容结构和避坑点不同。拆解 / 复刻时先定位赛道，再套对应模板。

> 用法：先判断内容属于哪个赛道 → 用该赛道的「标题公式偏好 + 内容结构」套 `viral-formulas.md` 里的具体公式 → 产出后过 `compliance-guardrails.md` 自检。

## 1. 职场 / 副业 / 搞钱

- **痛点**：加班、工资低、内耗、想搞副业没方向
- **标题公式偏好**：#1 数字结果、#3 身份认同、#6 对比
- **内容结构**：清单体 / 干货体
- **CTA**：收藏 + 评论区
- **封面**：数字大字（如「3千→3万」）
- **避坑**：金融投资词（稳赚 / 保本 / 荐股）、绝对化

## 2. 健身 / 减肥 / 体态

- **痛点**：反弹、没时间、坚持不下去
- **标题公式偏好**：#1 数字结果（前后体重）、#4 反常识
- **内容结构**：清单体 + 前后对比
- **CTA**：收藏 + 打卡
- **封面**：前后对比 + 数字
- **避坑**：减肥绝对化（根治 / 特效 / 不反弹）、医疗承诺

## 3. 美妆 / 护肤

- **痛点**：踩雷、选不对、烂脸
- **标题公式偏好**：#5 设问、#8 稀缺、#10 见证
- **内容结构**：对比体 / 干货体
- **CTA**：收藏 + 评论区问肤质
- **封面**：产品对比 / 效果图
- **避坑**：医疗功效承诺、绝对化（最好用 / 天花板）

## 4. 母婴 / 育儿

- **痛点**：焦虑、信息差、带娃累
- **标题公式偏好**：#3 身份认同、#9 清单体
- **内容结构**：清单体 / 故事体
- **CTA**：收藏 + 评论区
- **封面**：温馨场景 + 清单大字
- **避坑**：医疗（宝宝生病建议就医）、绝对化

## 5. 美食 / 探店

- **痛点**：不知道吃什么、踩雷
- **标题公式偏好**：#1 数字、#6 对比、#7 情绪词
- **内容结构**：对比体 / 故事体
- **CTA**：收藏 + 评论区
- **封面**：食物特写
- **避坑**：夸大（天花板 / 第一）、绝对化

## 6. 学习 / 读书 / 成长

- **痛点**：拖延、学不进去、没方法
- **标题公式偏好**：#9 清单体、#1 数字、#3 身份认同
- **内容结构**：干货体 / 清单体
- **CTA**：收藏 + 打卡
- **封面**：大字干货标题
- **避坑**：教育绝对化（保过 / 必过）

## 7. 理财 / 省钱

- **痛点**：存不下钱、被割韭菜
- **标题公式偏好**：#6 对比、#4 反常识、#1 数字
- **内容结构**：清单体 / 对比体
- **CTA**：收藏 + 评论区
- **封面**：数字对比
- **避坑**：金融投资词（稳赚 / 保本 / 荐股）——**重点雷区**

## 8. 情感 / 人际

- **痛点**：内耗、被拿捏、关系困惑
- **标题公式偏好**：#7 情绪词、#4 反常识、#3 身份认同
- **内容结构**：故事体 / 对比体
- **CTA**：评论区聊
- **封面**：情绪感图片 + 大字
- **避坑**：绝对化（「所有男人 / 女人都…」）、低俗

## 使用规则

1. 赛道只是起点，最终文字必须原创，套的是结构不是原文。
2. 一个内容可能跨赛道（如「副业 + 理财」），取交集后选更严的避坑规则。
3. 每类模板都可进一步扩展；提交新赛道模板是很好的贡献方式。
