# 爆款公式库

拆解时用它给一篇爆款「贴标签」，复刻时用它套公式。公式是结构，不是原文。

## 一、标题公式（10 类）

| # | 公式 | 示例句式 |
|---|---|---|
| 1 | 数字 + 结果 | 「3 步」「月入 X 万」「7 天」「保姆级」 |
| 2 | 痛点直击 | 「还在为 XX 发愁的人看过来」「XX 救星」 |
| 3 | 身份认同 | 「给 XX 的人」「XX 人的自救指南」 |
| 4 | 反常识 / 颠覆 | 「越 XX 越 XX」「别再 XX 了」 |
| 5 | 设问 / 悬念 | 「为什么 XX」「XX 的秘密」 |
| 6 | 对比冲突 | 「会 XX 和不会 XX 的区别」「穷人和富人差在哪」 |
| 7 | 情绪词 | 「后悔没早看到」「破防了」「救命」「谁懂啊」 |
| 8 | 稀缺 / 时效 | 「现在不看就晚了」「2026 最新」 |
| 9 | 清单体承诺 | 「X 个方法」「手把手」「从 0 到 1」 |
| 10 | 结果前置 / 见证 | 「从 XX 到 XX，我只做了 XX」 |

## 二、开头钩子（6 类）

1. **反常识开场**：先说一个违背直觉的结论。
2. **痛点 / 损失厌恶**：直戳读者正在经历的痛，制造「不看会亏」。
3. **故事开场**：一个具体、有细节的小故事。
4. **结果前置**：先亮结果，再讲方法。
5. **身份代入**：「你是不是也……」，让读者对号入座。
6. **恐吓 / 紧迫**：制造时间或机会的紧迫感。

## 三、情绪曲线（标准 5 段）

```
钩子(抓注意力) → 痛点放大(共情) → 转折(给方法) → 干货(可执行) → 结果/CTA(引导行动)
```

拆解时把爆款正文归到这 5 段，找出它的「情绪起伏点」。

## 四、信息结构（5 体）

| 结构 | 特征 | 适合 |
|---|---|---|
| 总分总 | 结论 → 分点 → 总结 | 干货、教程 |
| 清单体 | 「X 个方法」逐条列出 | 收藏向、工具向 |
| 故事体 | 完整叙事 + 反转 | 情感、涨粉 |
| 干货体 | 纯方法，密度高 | 知识、技能 |
| 对比体 | 前后 / 对错对比 | 种草、认知 |

## 五、组合示例（一个完整公式）

> 标题公式「结果前置 + 数字」+ 钩子「痛点直击」+ 情绪曲线「痛点放大→3 个方法→结果」+ 清单体 + CTA「点赞收藏」。
>
> 这是小红书「干货收藏向」最典型的爆款组合。

## 六、进阶：更多标题公式（#11–#15）

| # | 公式 | 示例句式 |
|---|---|---|
| 11 | 争议 / 引发讨论 | 「XX 到底值不值得买」「只有我觉得 XX 吗」 |
| 12 | 场景代入 | 「当你 XX 的时候」「打工人中午吃什么」 |
| 13 | 福利 / 免费 | 「免费领」「白嫖」「手慢无」 |
| 14 | 见证 + 时间 | 「坚持 30 天后我 XX」「一年后回头看」 |
| 15 | 悬念留白 | 「第 3 条最重要」「看到最后」 |

## 七、进阶：更多钩子（#7–#8）

7. **反问 / 挑衅**：用一句反常识的反问，挑起情绪。
8. **权威背书 / 数据开场**：先用一个具体数字或权威结论定调。

## 八、情绪曲线变体（4 种）

| 曲线 | 走向 | 适合 |
|---|---|---|
| 干货收藏曲线 | 痛点 → 方法 → 清单 → 结果 | 教程、工具 |
| 带货种草曲线 | 场景 → 痛点 → 产品方案 → 信任 → CTA | 种草、带货 |
| 情感共鸣曲线 | 故事 → 情绪高点 → 转折 → 升华 | 情感、涨粉 |
| 反转剧情曲线 | 铺垫 → 反常识反转 → 解释 | 剧情、认知 |

## 使用规则

1. 先判断爆款用了哪几类公式，再让用户选题套**同一类**公式，而不是照搬文字。
2. 垂直赛道的「痛点 + 标题偏好 + 结构 + 避坑」见 `references/niche-templates.md`。
3. 公式只是起点，最终文字必须原创，并通过 `references/compliance-guardrails.md` 自检。
